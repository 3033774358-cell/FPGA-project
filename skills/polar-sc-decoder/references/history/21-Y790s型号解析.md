### User

威视锐 Y790s，这是什么是fpga型号吗

---

### ChatGPT

不是。威视锐 YunSDR Y790s 不是 FPGA 的具体型号，而是一整套高性能软件无线电（SDR）设备/开发平台。 V3Best+1
它的核心芯片才属于 FPGA/SoC 范畴。Y790s 主要采用 AMD/Xilinx Zynq UltraScale+ RFSoC ZU47DR，部分配置可选 ZU48DR。RFSoC 可以理解为把 FPGA 可编程逻辑 + ARM 处理器 + 高速 ADC/DAC 集成在一颗芯片里。OneTest
简单对应关系是：
威视锐 / YunSDR → 品牌/产品系列
Y790s → SDR 整机/开发平台型号
ZU47DR / ZU48DR → Y790s 内部的核心 RFSoC 芯片型号
FPGA → ZU47DR 芯片内部的一部分可编程逻辑
Y790s 本身规格很高，支持 1 MHz–6 GHz、8 路发射 + 8 路接收、单通道最高 2 GHz 瞬时带宽、ADC 最高 5 GSPS，所以它更像一个“带射频前端、ADC/DAC、FPGA、ARM、DDR、高速光口的完整无线通信开发平台”，而不是传统意义上的一块 FPGA 开发板。OneTest
另外，它标配的 FX200 PCIe 前传加速卡里面还有另一颗 FPGA——Kintex UltraScale+ KU15P；可选 FX800 则使用 Virtex UltraScale+ VU13P。OneTest
所以如果你是在做 FPGA 开发/通信算法移植，别人跟你说“用 Y790s”，通常实际是让你在 Y790s 的 ZU47DR RFSoC 的 PL（FPGA）部分进行开发，而不是说 Y790s 就是 FPGA 型号。

### ChatGPT

你在 Vivado 里不能只按“Y790s”选，关键要对应它板上那颗 RFSoC 的完整料号：器件 + 封装 + 速度等级。我查到 Y790s 标配是 ZU47DR，但还要确认你这台机器的具体配置。

如果你这台是常规配置的威视锐 Y790s，在 Vivado 里应该按 Zynq UltraScale+ RFSoC → ZU47DR 来选，不是搜 Y790s。厂家资料明确写的是 ZU47DR，另有 ZU48DR 选配版。OneTest
在 Create Project → Default Part → Parts 里，建议先这样筛：
Family：Zynq UltraScale+ RFSoC
Device：xczu47dr
然后再选对应的 Package / Speed Grade。
这里要特别注意：先别随便选完整料号。 AMD 官方资料显示 XCZU47DR 本身存在多个封装，例如 FFVE1156、FSVE1156、FFVG1517、FSVG1517，所以仅凭“Y790s”我现在还不能负责任地告诉你最终一定是哪个 xczu47dr-xxxxxxx。AMD 文档+1
如果你只是先建工程写 RTL、做仿真，可以先找到：
xczu47dr
但如果后面要综合、实现、生成 bitstream 并真正烧到 Y790s 上，那么封装和速度等级必须跟板子上的实际芯片完全一致。
最简单的确定方法
如果厂家给了 Y790s 的原始 Vivado 工程 .xpr，打开后在 Vivado Tcl Console 输入：
tclget_property PART [current_project]
它会直接返回类似：
Plain textxczu47dr-2-ffve1156-i
这样的完整 Part 型号，然后你的新工程照着选即可。
你如果把 Vivado “Default Part”里搜索 xczu47dr 后出现的那几个型号截图发我，我可以直接告诉你选哪一个。
